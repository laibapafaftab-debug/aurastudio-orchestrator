# Security Policy

## Reporting a vulnerability

If you believe you have found a security issue with this website, please email **laibapafaftab@gmail.com** with a short description and steps to reproduce it. Please do not post the details publicly until it has been fixed.

## Scope

This is a static website (HTML, CSS and JavaScript) with no database or user accounts. Reports about the contact form, the page's Content Security Policy, or third-party services it loads are welcome.
